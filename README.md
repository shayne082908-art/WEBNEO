# WEBNEO

A tablet-first browser writing app inspired by Hugh Howey's open-source NEO editor.

## Build 03 — Idea Forge

Build 03 keeps the Build 02 writing flow and adds an **offline creative prompt engine**.

Idea Forge includes Premise, Scene, Character, and Challenge modes; genre and mood filters; lockable prompt ingredients; selective rerolling; saved sparks; clipboard copy; manuscript pinning; and a one-tap 15-minute writing practice.

Idea Forge does not require AI or an internet connection after the app is cached.
