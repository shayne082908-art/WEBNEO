# WEBNEO

A tablet-first browser adaptation of Hugh Howey's open-source NEO writing app, with additional creative tools layered on only after the core NEO experience is matched.

## Current build — Build 04: NEO Parity Pass 1

The project priority is now **NEO parity first, WEBNEO-only extras second**.

This build adds:
- first-run author / pantser-vs-plotter / page-style setup
- author and pen-name switching
- multiple named shelves
- desktop drag/drop plus touch-friendly move controls for books
- shelf reorder controls and drag handles
- six generated cover-art treatments × six title layouts
- cover reroll, custom cover image picker, and cover goal progress bars
- chapter notes in the left drawer
- chapter / prologue / epilogue types
- structured chapter/section outlining
- outline section notes as gray manuscript ghost paragraphs that turn into prose when typed over
- deliberate spellcheck, off during normal drafting
- typeface, drop cap, focus, typewriter, and text-size controls
- chapter/book word-count toggle
- 30-day momentum chart
- all Build 02/03 drafting features, including Darlings, placeholders, sprints, and Idea Forge

See `PARITY.md` for the upstream NEO feature matrix.
