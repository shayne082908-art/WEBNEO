# WEBNEO

A tablet-first browser writing app inspired by Hugh Howey's open-source NEO editor.

## Build 03 — Idea Forge

Build 03 keeps the NEO-style drafting flow and adds an offline prompt engine for the days when the blank page is winning.

### Writing features
- bookshelf, books, chapters, autosave and JSON backup/restore
- NEO-style Enter flow: paragraph → scene break → new chapter
- Shift+Enter poetry paragraphs and smart punctuation
- placeholders, Darlings, Notes, Outline
- daily/book goals and timed word sprints
- focus mode, typewriter scrolling and tablet-responsive controls

### Idea Forge
- Story Seed, Scene Drill, Character Pressure and Opening Drill modes
- genre and mood filters
- seven independently lockable prompt ingredients
- reroll unlocked pieces or generate a completely fresh spark
- save up to 50 sparks per book
- copy prompts
- pin a prompt above the manuscript without adding it to manuscript text
- launch the current spark directly into a 15-minute writing sprint
- works locally/offline with no AI account
