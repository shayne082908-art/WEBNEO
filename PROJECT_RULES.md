# Project Rules

1. Writing remains the primary activity; tools should disappear when not needed.
2. The core editor, local storage and Idea Forge must work without AI, an account, or a network connection after installation.
3. Never silently modify manuscript prose. Helpers propose; the writer decides.
4. Generated prompts and AI suggestions must remain separable from manuscript text unless the writer explicitly inserts them.
5. Tablet and touch behavior are first-class, not desktop afterthoughts.
6. Preserve reliable autosave and explicit backup/restore before adding clever features.
7. Build one reviewed slice at a time. Do not implement later roadmap items merely because interfaces exist.
8. Prefer small browser-native dependencies and transparent data formats.
9. Preserve NEO attribution and its MIT license notice where applicable.
10. Third-party code/assets require verified licensing and documentation.
